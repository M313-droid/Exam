# SK-CMS Online Examination — النسخة الأولى

## ما الذي تتضمنه؟
- واجهة عربية تعمل على متصفح Android ويمكن إضافتها للشاشة الرئيسية كتطبيق PWA.
- حساب مدير رئيسي ومديرين مساعدين، بحد إجمالي 7 مديرين.
- حساب منفصل لكل طالب.
- إنشاء امتحانات وأسئلة: اختيار من متعدد، صح/خطأ، إجابة قصيرة، ومقالية.
- مدة لكل سؤال، وإغلاق يدوي من المدير.
- استقبال إجابات الطلاب ومراجعتها ورصد الدرجات.
- نشر درجة كل طالب بعد اعتماد المدير.

## تنبيه مهم حول حالة النسخة
هذه حزمة مصدر أولية قابلة للربط بـ Firebase وليست خدمة مستضافة وجاهزة بعد. لا يمكن أن تعمل المزامنة بين الهواتف قبل إنشاء مشروع Firebase وإدخال إعداداته ونشر قواعد Firestore. كما أن النسخة الحالية هي MVP للاختبار وليست بعد نظاماً إنتاجياً معتمداً؛ يجب اختبار الصلاحيات والتزامن والمهل الزمنية قبل استخدامها في امتحان رسمي.

## الإعداد من هاتف Android
1. افتح https://console.firebase.google.com وأنشئ مشروعاً باسم SK-CMS-Online-Exam.
2. أضف تطبيق Web للمشروع، وانسخ إعدادات Firebase الظاهرة.
3. فعّل Authentication ثم Email/Password.
4. أنشئ Firestore Database.
5. من تبويب Rules انسخ محتوى `firestore.rules` ثم اضغط Publish.
6. في `app.js` استبدل القيم `PASTE_...` بإعدادات مشروعك.
7. ارفع ملفات المجلد إلى استضافة HTTPS تدعم الملفات الثابتة (Firebase Hosting). إعداد Hosting الأولي قد يكون أسهل من حاسوب؛ يمكن استخدام خدمة استضافة ملفات ثابتة من لوحة ويب على الهاتف إذا كانت تتيح رفع مجلد/ZIP.

## إنشاء المدير الرئيسي لأول مرة
1. من Firebase Authentication أنشئ مستخدماً ببريدك وكلمة مرور.
2. انسخ UID الخاص به.
3. من Firestore أنشئ مجموعة `users` ثم مستنداً يكون معرّفه UID نفسه.
4. أضف الحقول:
   - `displayName`: اسم المدير
   - `role`: `mainAdmin`
   - `enabled`: `true`
5. سجّل الدخول من التطبيق. بعد ذلك يستطيع المدير الرئيسي إنشاء حسابات الطلاب والمديرين المساعدين من الواجهة.

## حدود النسخة الأولى التي يجب استكمالها قبل الاستخدام الفعلي
- إضافة لوحة ترتيب عامة كاملة بعد نشر النتائج، لا مجرد نتيجة الطالب الفردية.
- إضافة التحقق من الدرجة القصوى لكل سؤال عند الحفظ.
- تنفيذ تصحيح آلي للإجابات القصيرة عند الحاجة أو اعتمادها يدوياً.
- إضافة حماية خادمية موثوقة لإغلاق السؤال عند انتهاء الوقت، وإدارة التزامن عبر Cloud Functions.
- تحسين إدارة الامتحانات المكتملة وإعادة فتحها، وتصدير النتائج.
- مراجعة قواعد Firestore واختبارها بحساب مدير وحساب طالب قبل إطلاقها.

## ملاحظة تشغيل
لا تضع مفاتيح سرية أو بيانات حساسة في الملفات العامة. إعدادات Firebase Web تتضمن عادة مفاتيح تعريف للمشروع وليست بديلاً عن قواعد الأمان. الأمان الفعلي يعتمد على Authentication وقواعد Firestore وخدمات الخادم.
